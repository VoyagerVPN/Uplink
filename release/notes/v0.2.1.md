## 🖥️ UI

✦ **New** — A spinner shows which setup step is running. Once the network is ready, you can choose its photo and copy the invitation from the same screen.

✓ **Fixed** — Setup remembers your installation folder, and “Open Uplink” launches the client from that folder.

## 🌐 Net

✦ **New** — Stay connected to networks on different VPS hosts at the same time through one Uplink adapter.

↻ **Changed** — Your membership lasts until you leave or are removed. After a long break, Uplink renews your device key and reconnects with the same IP address.

## 🛠️ For server owners

↻ **Changed** — Uplink now uses EasyTier. If you host a ZeroTier-based Uplink network, set up a new instance and send your friends fresh invitations.

✓ **Fixed** — VPS setup now works on Windows PCs where the SSH key check previously failed before the password was sent.
