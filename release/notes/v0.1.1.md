## 🔌 Fewer background connections

Uplink now reuses its HTTPS connection when refreshing your network. When you join, it checks your PC for its virtual IP and spaces out retries while the server is still approving the invitation.

## 🖱️ Network controls in the tray

Turn Uplink on or off from the tray menu. You can preview all three tray icons and switch between them while the menu stays open.

## 🛠️ For server owners

The server can process other joins while one PC is waiting for approval. On Windows PCs that already have ZeroTier set up for Uplink, you can now join from the command line without opening a window.
