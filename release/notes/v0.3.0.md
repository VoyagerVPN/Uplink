## 🧩 Features

✦ **New** — Send, cancel, and decline SSH access requests between members of a network.

Approving requests and opening SSH sessions are still in development.

## 🖥️ UI

↻ **Changed** — The redesigned network view puts nicknames, roles, ping, and IP addresses in one table, with power and notifications in the title bar.

✦ **New** — Choose your nickname on first launch, change it in Settings, or pick a different one for a network from your own row.

✦ **New** — Open release notes and incoming SSH requests from the notification bell, and see cancelled and declined requests in History.

↻ **Changed** — Choosing to delete local data during uninstall now also removes the SSH keys managed by Uplink.

↻ **Changed** — If an update fails, Uplink records the step and error code so the installation can be diagnosed.

## 🌐 Net

✦ **New** — Copy the server address or an invitation link, show a QR code, or open saved sign-in details from the network menu.

## 🛠️ For server owners

✦ **New** — Update an existing VPS from the network menu, with a backup, automatic rollback, and a copyable progress log.

✦ **New** — See the server version in the network menu and get a notification when your VPS can be updated.

✦ **New** — Owners and administrators can edit eligible participants’ nicknames from the member list.

↻ **Changed** — Members can share invitation links and QR codes when those methods are enabled.

Open **⋮ → Update server** in a network you own to enable SSH requests, network nicknames, and invitation sharing for members.
