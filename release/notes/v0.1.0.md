## 🌐 Play on the same LAN

Uplink puts you and your friends on the same private network, even when you’re playing from different homes. You can see who’s online, check your ping to a friend, and copy their IP if a game asks for an address. Play with a few different groups? Pick a network from the sidebar to see who’s there.

## 🚀 Join your friends

Run **Uplink-Setup.exe** on 64-bit Windows, then open Uplink. Ask the friend who runs your group’s Uplink server for an invite link and paste it into the app. You can also join with the server address, network name, and password.
