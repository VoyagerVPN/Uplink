## 🖥️ UI

↻ **Changed** — Joining, invitations, avatar editing, VPS setup, and updates now use a consistent dialog layout.

✓ **Fixed** — Long errors scroll inside dialogs so their buttons stay reachable, and closing a dialog returns keyboard focus to its opener.

✓ **Fixed** — The update window shows the star next to new features, and Russian avatar errors appear in Russian.

## 🌐 Net

✓ **Fixed** — With auto-connect on, Uplink restores saved connections at startup, shows when Windows is preparing the adapter, and retries a failed service start.

✓ **Fixed** — Peer ping updates every five seconds independently of server sync and retries a timeout once before clearing the reading.

↻ **Changed** — Windows protects membership tokens for your account. If you roll back to an older Uplink version, use a fresh local profile and rejoin your networks.

## 🛠️ For server owners

✦ **New** — The Windows client records HTTP and Windows error codes in a rotating transport log to help diagnose network sync and adapter failures.
